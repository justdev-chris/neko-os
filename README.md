# NekoOS 🐱

A simple hobby operating system with a cat theme.

## Features
- Text mode terminal
- Working keyboard input
- Shell with commands
- Snake game
- Cat ASCII art
- Uptime counter
- Memory info
- BSOD (Blue Screen of Death) for errors

## Commands
```
help      - Show available commands
clear     - Clear the screen
snake     - Play the Snake game
neko      - Display a cat
reboot    - Reboot the system
uptime    - Show system uptime
meminfo   - Show memory information
catclock  - Display an animated cat clock
panic     - Test the BSOD
```

## Building
```
make clean
make
make run
```

## Requirements
- GCC cross-compiler (i686-elf)
- NASM
- QEMU (for testing)
- GRUB (for ISO creation)
